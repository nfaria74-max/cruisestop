# Images Folder

This folder contains images used in the CruiseStop PWA.

## Current Images

- `funchal-hero.webp` - Hero background image showing panoramic view of Funchal with cruise ship

## Instructions

To add the Funchal panoramic image:

1. Save the panoramic image of Funchal with the cruise ship as `funchal-hero.webp` in this folder
2. Recommended size: 1920x1080 pixels
3. Format: WebP for better performance (or JPEG if preferred)
4. File size: Keep under 500KB for fast loading

## Alternative

If you don't have WebP format, you can:
- Use JPEG format and update the CSS reference
- Convert the image using online tools like TinyPNG or Squoosh
